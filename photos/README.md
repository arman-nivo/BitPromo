# Creator photos

Each creator has a portrait here, mapped by id in photos.js
(c1 ayesha.jpg ... c20 junaid.jpg).

These are AI-generated portraits of fictional people (made with Canva's image
generator), so they show no real person or celebrity. They were upscaled 4x
(161x200 to 644x800 px) so they stay sharp on retina screens: Real-ESRGAN for
hair, clothes and background, GFPGAN v1.4 face restoration for natural eyes and skin.
For a client launch, swap in your own shoots at higher resolution: keep the
same file names, or edit photos.js.

Delete a file or its photos.js entry and that creator falls back to the drawn avatar.
